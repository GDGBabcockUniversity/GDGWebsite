# Core Team layout in the CMS

Open Studio → Team → Current team (or Past teams), then edit a member in
the Core section.

- **Layout row:** Members with the same number appear together. Lower row
  numbers appear first. Leave this blank to use the automatic lead/member
  layout below any numbered rows.
- **Display order:** Lower numbers appear further left within a numbered row.
  Equal values are ordered by name. The Lead flag does not override numbered rows.

For a 2–4 arrangement, assign two members to Layout row **1** and four members
to Layout row **2**. Set their Display order values in the desired reading order.
For 3–3, assign three members to each row instead. Publish each edited member.

Rows are centered and fit up to four cards on desktop. Smaller screens wrap
cards into two columns. More than four members in a numbered row wrap on desktop.
Layout settings belong to each member's team year and subteam, so past teams
can have their own arrangements. Other sections retain their automatic layout.

Published changes may take up to an hour to appear because roster content is cached.
